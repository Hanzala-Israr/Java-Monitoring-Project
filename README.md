# Java Demo Application

This is a Java-based demo application built as part of a DevOps Bootcamp.
The application displays system information and environment variables and is designed to be used for practicing build tools, containerization, and deployment.

---

## 📌 Features

* Displays system information
* Shows environment variables
* Java-based backend
* Build tool integration
* Ready for Docker and Kubernetes deployment
* Cloud-friendly (Tested on Linux/AWS)

## 🔧 Prerequisites

Make sure you have installed:

* Java 17
* Maven
* Git

Check versions:

```
java -version
mvn -version
git --version
```

---

## 🚀 Build Instructions

Clone the repository:

```
git clone https://github.com/your-username/java-demo-app.git
cd java-demo-app
```

Build the project:

```
mvn clean install
```

---

## ▶️ Run the Application

Run the application using:

```
java -jar target/*.jar
```

Then open in browser:

```
http://localhost:8080
```
